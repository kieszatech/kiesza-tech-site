The driver USP

Route changes become decisions, not surprises.

BulletNAV keeps route state visible and makes rechecking explicit. If conditions move, the driver can see what changed and compare the outcome before an eligible replacement is adopted.

01

Approved route execution

Execute the route geometry selected upstream rather than silently replacing it with a different route.

02

Navigate Now

Open the driver navigation experience even when no route is pre-assigned, then select a vehicle and add a route when required.

03

Locked vehicle context

Keep the active HGV profile visible so the driver knows which vehicle envelope the route was checked against.

04

CHECK ROUTE

Compare the current route with a new checked alternative and show the ETA delta before any change is accepted.

05

Deviation awareness

Distinguish on-plan, alternative and off-baseline states so the driver and Control Tower share the same journey context.

06

Live journey feedback

Position, progress, ETA and route events feed back into Fleet to keep the Control Tower current.
